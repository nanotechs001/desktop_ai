# GoHighLevel funnel / website builder

Confirm each step in the live UI; GHL changes often and white-label apps (custom domains) look the same inside.

## Layout of the builder (seen in the builder iframe, frame "funnel-builder")
- Top bar: Back, autosave status, Publish, zoom ("100%"), preview link, Connect Domain, Page.
- **Quick Add** panel: **Sections**, **Rows**, **Elements** (plus templates/saved items when shown).
  - Sections: width options (Full Width, Wide, Medium, Small).
  - Rows: 1 to 6 columns.
  - Elements: Headline, Sub-Headline, Paragraph, Bullet list, Button, Image, Video, Form and more (scroll the panel for the rest).
- Selecting a section, row, column or element on the canvas opens its settings on the side; a selected column shows an **Add** button for elements.
- A save with no sections shows "No sections found…": close it with Cancel; it is not an error.

## Fast path
1. Add all sections first (Sections → width), then rows in each (select the section → Rows → columns), then elements per column (select the column → Add → element).
2. Finish one section, then duplicate it (the section's toolbar/menu) and edit the copy.
3. Style through the selected item's settings (colors, typography, spacing, background) before any custom CSS. Use the page/funnel settings for custom CSS or code only for what the controls cannot do.
4. The builder autosaves; Publish only when the user asks.
